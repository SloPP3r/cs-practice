diff - показывает разницу коммитов
log - показывает коммиты, параметр stat дополнительно выводит измения эти коммитов
show - показывает информацию о коммите
blame - показывает строки коммиты, в которых они были добавлены, и автора
git log -s"def" - показывает коммиты затронувшие искомый файл и регулярное выражение
