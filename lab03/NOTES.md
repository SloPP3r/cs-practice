diff - показывает разницу коммитов
log - показывает коммиты, параметр stat дополнительно выводит измения эти коммитов
show - показывает информацию о коммите
blame - показывает строки коммиты, в которых они были добавлены, и автора
git log -s"def" - показывает коммиты затронувшие искомый файл и регулярное выражение
restore - возвращает состояние файлов к индексу
restore --sorce= - возвращает состояние фалов к указанному коммиту
revert - создаёт новый коммит с отменой измений выбранного коммита
reset --hard - возвращает в состояние выбранного коммита(индекс и пабочую область)
может быть прменено только для неопубликованных коммитов
ветка - отдельный путь разработки
тег - якорь, которым можно пометить важный коммит
