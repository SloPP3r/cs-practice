рабочая папка - директория, в которой находится гит репозиторий
индекс - временно сохраннёные изменения фалов в т.ч. создание новых
коммит - чекпоинт, который создан из индекса
Git - способ контроля и управления изменениями в коде
Github - один из агрегаторов git
Использованные комманды:
git status - показывает состояние репозитория (отслеживаемые, изменённые, новые файлы и пр.)
git diff  - сравнивает рабочую директорию и индекс
git diff --staged - сравнивает индекс и HEAD коммит
Ветки:
Ветка - это отдельный путь разработки, при новом коммите, он добавляется к текущей выбранной ветке и никак не отражается на других
Слияние вливает изменения из одной ветки в другую
